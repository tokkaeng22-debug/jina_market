## 1. 프로젝트
- 1인 크리에이터가 **동영상 강의 · 전자책 · 라이브 미팅**을 직접 판매하는 사이트입니다. 다른 판매자가 입점하는 마켓플레이스가 아닙니다.
- 국내(한국어, KRW)와 해외(영어, USD) 고객을 함께 받습니다.
- 모바일 우선으로 설계하고, 데스크톱은 반응형으로 확장합니다. 관리자 화면만 데스크톱 우선입니다.

### ★ 운영자가 이 레퍼런스를 고른 이유: **색감**과 **귀여운 캐릭터**
이 두 가지가 디자인의 중심입니다. 나머지(레이아웃 등)는 와이어프레임을 따르면 됩니다.

**① 색감 — 맑은 스카이블루**

아래는 이미지에서 뽑은 추정치이니 같은 느낌으로 보정해 주세요.

| 역할 | 느낌 | 추정 HEX |
|---|---|---|
| Primary (헤더 · 탭 배경) | 하늘색에 가까운 밝은 블루, 탁하지 않게 | `#3D9BFA` 부근 |
| Primary Strong (CTA 버튼 · 강조 텍스트) | 한 톤 진한 블루 | `#2B87F0` 부근 |
| Surface Tint (배너 · 카드 배경) | 아주 연한 블루그레이 | `#EEF4FB` 부근 |
| Background | 순백 | `#FFFFFF` |
| Point (응원 · 성취) | 따뜻한 옐로/골드 (폼폼 색) | `#F6C21C` 부근 |
| Sparkle (장식) | 보라 · 핑크 · 블루 작은 별 | 소량만 |
| Text | 거의 검정에 가까운 짙은 회색 | `#1F2329` 부근 |

- 큰 면적은 블루와 흰색 두 가지로 깔끔하게 유지하고, 옐로와 반짝이는 포인트로만 씁니다.
- 헤더 블루 위의 텍스트 · 아이콘은 흰색으로 씁니다. 흰 탭 카드가 블루 헤더 위로 둥글게 겹치는 구조(04번)를 살려 주세요.

**② 귀여운 3D 마스코트 — jina_market 전용 캐릭터를 새로 만들기**

> ✅ 2026-11-06 결정: **C 별 "반짝"** (목표를 이루는 순간, 방울에서 변경). 캐릭터 시트 7포즈: https://claude.ai/artifact/EfkcueHuAX1CemUDnuXVCH

- 스타일만 가져옵니다:
  - 말랑하고 광택 있는 3D 렌더 질감
  - 흰색에서 하늘색으로 넘어가는 그라데이션
  - 점 눈과 작은 입만 있는 단순한 얼굴
  - 짧은 팔다리, 통통한 실루엣
- **상상단의 구름 캐릭터를 그대로 쓰거나 비슷하게 따라 그리면 안 됩니다** (저작권 · 브랜드 혼동). 같은 질감과 색감으로 **다른 모티프**의 캐릭터를 2~3가지 제안해 주세요. 예를 들어 책장 · 말풍선 · 물방울 · 별 · 노트처럼 "배움, 성장"과 연결되는 오브젝트, 또는 운영자 이름 "jina"에서 착안한 형태도 좋습니다.
- 캐릭터 시트: 정면 기본, 손 흔들기(인사), 응원(폼폼), 책 들기(공부), 축하(점프), 생각 중(빈 상태), 미안해요(오류)
- 화면별 사용 위치:
  | 화면 | 포즈 |
  |---|---|
  | 홈 히어로 · 리드 마그넷 배너 | 손 흔들기 + 반짝이 |
  | 내 학습 (이어서 보기 · 연속 학습) | 응원 |
  | 전자책 상세 · 다운로드 | 책 들기 |
  | 결제 완료 · 강의 수료 · 과제 피드백 도착 | 축하 |
  | 빈 상태 (구매 내역 없음 등) | 생각 중 |
  | 404 · 오류 | 미안해요 |
- 웹 성능: 캐릭터는 투명 배경 WebP/AVIF로 쓰고, 1x/2x 크기를 함께 준비합니다. 첫 화면 히어로 이미지는 200KB 이하로 맞춥니다.

**③ 배지 컬렉션 (03번 참고)**
- 원형 배지 안에 3D 아이콘을 넣고, 하단에 짙은 리본 라벨(예: "3일", "수료")을 다는 형식입니다.
- jina_market용 배지: 회원가입, 첫 결제, 첫 레슨 완료, 연속 학습 3 · 7 · 30일, 과제 첫 제출, 강의 수료, 라이브 첫 참석
- 받지 못한 배지는 흑백 + 반투명으로 보여줍니다.

그 외에 가져올 것:
- 둥근 모서리 카드, 알약형 칩 · 버튼, 넉넉한 여백
- 진행률 바, 주간 학습 기록, 마감 D-day 배지
- 하단 탭바 내비게이션, 하단 고정 CTA

복제하지 말 것:
- 상상단의 로고, 캐릭터, 일러스트 원본, 문구
- 상상단은 앱이므로 웹사이트(SEO 본문, 긴 상품 상세, 블로그)에 맞게 타이포 위계를 강화해 주세요.

## 3. 브랜드 방향
- 키워드: 맑음, 귀여움, 응원, 꾸준한 성장. 귀엽지만 유치하지 않게, 전문가의 신뢰감도 유지
- 서체: 한글 Pretendard(제목은 Bold, 둥근 느낌), 영문도 같은 결의 산세리프. 모바일 본문 16px
- 색: 위 ① 팔레트 기준 + 상태색(성공 그린 · 경고 오렌지 · 오류 레드)
- 다크 모드: 배경은 짙은 네이비로 하고, 블루는 채도를 유지한 채 명도를 올립니다. 캐릭터는 그대로 씁니다.

## 4. 디자인할 화면 (와이어프레임 기준)
| 그룹 | 화면 |
|---|---|
| 공개 · 판매 | 홈, 강의 상세, 전자책 상세, 라이브 상세 (+ 상품 목록, 블로그 목록, About, FAQ) |
| 공통 | 푸터 (사업자 정보, 이용약관 · 개인정보처리방침 · 환불정책) |
| 결제 | 체크아웃 국내(₩, PortOne), 체크아웃 해외($, Lemon Squeezy 오버레이), 결제 확인 중 · 입금 대기 · 실패, 결제 완료 |
| 학습 | 내 학습 대시보드, 레슨 플레이어(스크립트 · 자료 탭), 마이페이지 |
| 게시판 | 블로그 글, 과제 목록, 과제 제출 |
| 관리자 | 대시보드 (데스크톱) |

## 5. 반드시 지켜야 할 기능 · SEO 제약
- 와이어프레임의 정보 구조와 번호 주석(①②…)을 유지해 주세요. 시각적으로만 다듬어 주시면 됩니다.
- **블로그 · 상품 상세의 본문은 실제 텍스트**여야 합니다. 이미지 안에 텍스트를 넣지 말아 주세요 (SEO/AEO/GEO).
- 블로그 글: 상단에 "핵심 요약" 박스, 작성일 · 수정일, 작성자 박스, 관련 상품 CTA
- 상품 상세: 빵부스러기(breadcrumb), FAQ 아코디언, 하단 고정 구매 바, 통화 표시(₩/$)
- 체크아웃(국내): 청약철회 제한 고지 체크박스(필수), 동의 전에는 결제 버튼 비활성
- 언어 전환(KO/EN) 버튼을 헤더에 넣어 주세요. 영어로 바꿨을 때 문구가 길어져도 레이아웃이 깨지지 않아야 합니다.
- 접근성: 텍스트 대비 WCAG AA 이상, 터치 영역 44px 이상, 상태를 색만으로 구분하지 않기
- Core Web Vitals: 히어로 3D 일러스트는 WebP/AVIF 정적 이미지로 처리하고, 무거운 애니메이션은 지양해 주세요
